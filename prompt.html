🤖 AI • Prompt Engineering

Prompt Engineering-এর ৮টি গুরুত্বপূর্ণ অংশ

ভালো Prompt = ভালো AI Output

Role + Task + Context + Input + Constraints + Format + Examples + Evaluation
01

🎭 Role / Persona

AI-কে কোন ভূমিকা পালন করতে হবে তা নির্ধারণ করুন।

উদাহরণ: “তুমি একজন অভিজ্ঞ Marketing Expert।”
02

🎯 Task / Instruction

AI-কে ঠিক কী কাজ করতে হবে তা পরিষ্কারভাবে বলুন।

উদাহরণ: “একটি LinkedIn Post লিখো।”
03

📚 Context

প্রয়োজনীয় Background ও পরিস্থিতির তথ্য দিন।

উদাহরণ: “Target Audience হলো তরুণ উদ্যোক্তা।”
04

📥 Input / Data

AI যে তথ্যের ওপর কাজ করবে সেটি প্রদান করুন।

উদাহরণ: Text, Data, Document বা প্রশ্ন।
05

📏 Constraints

কী কী নিয়ম বা সীমাবদ্ধতা মেনে চলতে হবে তা নির্ধারণ করুন।

উদাহরণ: “১৫০ শব্দের মধ্যে লিখবে।”
06

📋 Output Format

উত্তরটি কোন Format-এ চান তা নির্দিষ্ট করে দিন।

উদাহরণ: Table, Bullet, JSON বা Step-by-Step।
07

💡 Examples

কাঙ্ক্ষিত Output-এর একটি বা একাধিক নমুনা দিন।

উদাহরণ: “এই Sample-এর মতো উত্তর দাও।”
08

✅ Evaluation

একটি ভালো উত্তর কেমন হবে তার Quality Criteria দিন।

উদাহরণ: “নির্ভুল, সহজ ও ব্যবহারিক হতে হবে।”

🚀 Master the Prompt, Master the AI!
